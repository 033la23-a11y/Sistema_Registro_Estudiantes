# Guion breve para exposición (3 integrantes)

## Integrante 1 — Diseño y POO
"Nuestro proyecto es un sistema de registro de estudiantes. Utilizamos programación orientada a objetos. La clase Persona contiene nombre y edad; Estudiante hereda de Persona y agrega matrícula y carrera. Aplicamos validaciones y sobrescritura de métodos."

## Integrante 2 — Gestión y datos
"Yo desarrollé la lógica para registrar, buscar, listar y eliminar estudiantes. Utilizamos SQLite para guardar los registros incluso después de cerrar el programa. La matrícula funciona como identificador único y el sistema evita duplicados."

## Integrante 3 — Interfaz y pruebas
"Yo integré los módulos en una interfaz con Tkinter. El usuario captura los datos, utiliza los botones y consulta la tabla. Probamos registros exitosos, búsquedas y errores controlados, como una matrícula duplicada. También relacionamos el diagrama de clases con el código mediante una matriz de trazabilidad."

Personalizar las intervenciones según el trabajo realmente realizado por cada integrante.
